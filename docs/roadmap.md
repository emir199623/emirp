# AliSaParty Roadmap

## Phase 0: Foundations (Week 1-2)
- Finalize requirements and scope.
- Choose SFU (LiveKit recommended).
- Stand up repo structure and CI.

## Phase 1: MVP (Week 3-8)
- Flutter mobile app skeleton.
- Auth + profile flows.
- Room creation/join/leave with audio.
- Coin wallet + purchase verification.
- Gift sending + ledger.
- Admin panel moderation.

## Phase 2: Growth (Week 9-12)
- Families and family rooms.
- Custom IDs purchase flow.
- Anti-abuse automation.
- Analytics dashboards.

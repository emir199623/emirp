# AliSaParty

AliSaParty is a voice-first social app concept (Android APK) featuring live rooms, custom IDs, families (clans), a coin economy, and a full admin panel.

## Repository Layout
- `apps/mobile`: Flutter mobile app (Android APK).
- `apps/admin`: Admin panel (React).
- `services/api`: Backend API service.
- `docs`: Requirements, architecture, and data model.

## Next Steps
1. Confirm SFU provider (LiveKit recommended).
2. Choose backend language (Node.js or Go).
3. Create Flutter app skeleton and integrate voice SDK.
4. Stand up API with auth, rooms, and wallet endpoints.
5. Build admin panel for moderation and economy controls.

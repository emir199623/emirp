# Mobile App (Flutter)

Bu klasör AliSaParty Android APK için Flutter uygulamasını barındırır.

## Başlangıç
Proje iskeletini oluşturmak için:
```bash
flutter create --org com.alisaparty app
```

Oluşturulan uygulama `apps/mobile/app` dizininde yer alır.

## APK Build
Detaylı build adımları için: `docs/apk-build.md`
